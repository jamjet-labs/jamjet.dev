The first video code-along is out: [Build Your First AI Agent with JamJet](https://www.youtube.com/watch?v=VVLrZosEwhE), part 1, seven minutes. It builds a venue-booking agent on jamjet 0.13.0 from an empty folder, then adds a `pay_deposit` tool that pays because the prompt said so. Every step runs without an API key, and [the code for each step](https://github.com/jamjet-labs/jamjet/tree/main/examples/venue-booking-agent) is in the repo.
